The LinkML modeling language has emerged as a powerful schema driven data definition language (DDL) that harmonizes with many common data representation frameworks and formats. While authoring LinkML schemas is easily facilitated by editing simple YAML formatted files, non-technical users may find the development environments recommended for writing schemas less user friendly than graphical interfaces with intuitive interaction modalities. Visual UML-style editors that can export to DDLs like SQL are useful tools for modeling data that allow data domain experts both with and without substantial technical expertise to iterate quickly on data modeling projects. Here we present LinkML Modeler, an open source web based UML-style editor designed specifically for viewing and authoring LinkML schemas. Key features include a visual ERD canvas, real-time YAML generation and preview, schema validation, multi-schema support, tools for managing and editing large schedules, and built-in git integration. The editor was developed for and is in active use on a large data modeling project for the National Center for PTSD Brain Bank at the US VA. The project has mature documentation, demo, and code hosted on GitHub (https://github.com/BU-Neuromics/linkml-modeler-app).
