The LinkML modeling language has emerged as a powerful schema driven DDL that harmonizes with many common data representation frameworks and formats. While authoring LinkML schemas is easily facilitated by editing simple YAML formatted files, non-technical users may find the development environments recommended for writing schemas less user friendly than graphical interfaces with intuitive interactive interfaces. Visual UML-style editors that can export to data definition languages (DDLs) like SQL are useful tools for modeling data allow domain data experts without substantial technical expertise to contribute to data modeling projects.
